# tpmp-lab9-tarasova
## План тестирования (Test Plan) для ЛР №9

### 1. Объект тестирования
Приложение из лабораторной работы №8 (краткое описание, что делает приложение).

### 2. Область тестирования
- Модульное тестирование (Unit Tests) — тестирование отдельных классов/функций.
- UI-тестирование (UI Tests) — тестирование пользовательских сценариев.

### 3. Критерии качества
- Код проходит все модульные тесты.
- UI-тесты не падают при стандартных сценариях использования.

### 4. Стратегия тестирования
- **Unit Tests**: Проверка математических/логических функций, обработки ошибок, граничных значений.
- **UI Tests**: Проверка навигации, ввода данных, отображения элементов.

### 5. Необходимые ресурсы
- Xcode с симулятором iPhone.
- Git и GitHub для контроля версий.
